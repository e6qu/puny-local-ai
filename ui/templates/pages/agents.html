Agents

OpenCode, Pi and Codex can use the local model through their own configs, with a provider called puny, or through the launchers ./bin/opencode-qwen, ./bin/pi-qwen and ./bin/codex-qwen. Nothing else in their configs changes, and removing restores each file exactly.

Install agents

./bin/setup

At pinned versions, refusing any release less than 24 hours old. Codex installs with brew install codex.

Smoke test

./bin/smoke-test

Each installed agent must create a file through its own tools, against the running server.
