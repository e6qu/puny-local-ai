Benchmarks

Two ways to compare models. The agent benchmark runs whole coding agents on the tasks in bench/ and grades them with hidden tests. The evals ask the model directly: tool calls, coding problems, long context and speed. Both need the server running, and label their results with the model's name.

Verify a preset

./bin/verify

Checks one preset end to end on this Mac: downloads it if needed, starts its own server, runs the steps picked, stops the server, and writes a report to state/verify/ with the machine, the versions, the results and each request's memory peak against its estimate. It needs the port to itself, so stop the server on the Server page first. With all three steps it takes hours.
