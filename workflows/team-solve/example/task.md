# Problem: Longest Rising Run

You are given N integers A1 … AN (1 ≤ N ≤ 200000, |Ai| ≤ 10^9).
A rising run is a stretch of consecutive elements in which each element is
strictly greater than the one before it. A single element is a rising run of
length 1.

Print the length of the longest rising run.

## Input
The first line holds N. The second line holds the N integers, separated by
spaces.

## Output
One integer: the length of the longest rising run.

## Constraints
N up to 200000, so the solution must run in O(N) or O(N log N) time.

Write the program as solution.py reading stdin and printing the answer.
